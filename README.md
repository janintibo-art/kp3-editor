# mokteK KAOSS STUDIO
V1 Android expérimentale. Compilation GitHub Actions, site dans docs. Interface WebView locale et pont Android MIDI natif. Le mode simulation n'émet pas de son. Les profils utilisent les messages MIDI ordinaires; le protocole USB propriétaire et SysEx n'est pas implémenté. Tester sur KP3 et KP3+ avant utilisation en concert. Les sessions ne relisent pas la mémoire matérielle. Le BPM est local, sans horloge MIDI. La maquette est une référence artistique, pas une capture réelle. APK debug destiné aux tests. Pour les futures versions, prévoir une clé de signature persistante.
